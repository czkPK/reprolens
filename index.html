四个可验证功能

固定展示版重点保留最核心、最容易被评审检查的四部分。

完整报告

六维评分、25 项检查、证据编号和缺口。

声明矩阵

README 声称什么、需要什么证据、还缺什么。

AutoFix 验证

修改前后分数、保留与丢弃文件、原仓库不变校验。

评分 JSON

可被 CI、Webhook 或其他外部系统直接读取。
