## 4. 安全性检查

- 网页只接受 `https://github.com/owner/repo`；
- 拒绝 Issue、文件、子目录和非 GitHub 链接；
- 默认不执行被审计仓库代码；
- 页面说明不安装第三方依赖；
- 报告固定到 commit SHA；
- API Key 不写入报告或仓库；
- AutoFix 只在隔离 staging 副本中运行。
