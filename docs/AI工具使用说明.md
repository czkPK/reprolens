# AI 工具使用说明

## 一、使用目的

ReproLens 在开发过程中使用 Codex/ChatGPT 类 AI 编程助手辅助完成部分代码起草、测试用例补充、文档结构整理和表达润色。AI 不是项目事实判断的唯一来源，也不替代人工验收。

## 二、参与环节

| 环节 | AI 参与方式 | 人工审核与验证 |
|---|---|---|
| 需求与方案 | 辅助整理竞品、风险和任务拆分 | 团队确定问题范围、功能边界和提交方向 |
| 代码实现 | 辅助起草扫描、规则、报告和测试代码 | 逐文件审查，使用单元测试和真实仓库复跑 |
| 文档撰写 | 辅助组织结构、压缩表达和生成初稿 | 核对实验结果、许可证、链接和事实描述 |
| 报告解释 | 运行时可选调用 OpenAI-compatible 模型 | 结论必须绑定证据 ID；无证据时回退离线规则 |

## 三、AI 输出验证

1. 规则引擎负责文件存在性、评分、适用性和证据 ID；LLM 不直接决定分数；
2. AI 返回的 criterion ID 必须存在于检查项目录；
3. AI 只能引用仓库中已经抽取到的 evidence ID；
4. 返回格式异常、无证据或引用未知 ID 时自动回退规则模式；
5. 所有测试、holdout 数据和报告均由本人复核，不把 AI 描述当作实验数据。

## 四、数据和凭据

- 仓库中不保存 API Key、账号密码或访问令牌；
- 网页版只分析公开仓库；
- 不执行被审计仓库的业务代码；
- 不将第三方仓库源码随最终提交包分发；
- 不把公开可访问误认为当然具有训练、改编或再分发授权。

## 五、开放说明

AI 辅助生成的代码和文档已纳入 MIT 开源仓库，提交前经过人工运行测试、事实核对和语言修改。若后续接入外部模型服务，应继续遵守相应服务条款，并在资源清单中更新模型名称、版本、来源和许可信息。
