ReproLens Webhook 接收看板

这个页面用来证明：ReproLens 生成的评分 JSON 不仅能下载，还能主动发送给外部系统。下方展示的是接收端实际收到的数据。

Webhook（回调通知）一个系统在事件发生后，主动把结果发送给另一个系统的地址，不需要人工上传文件。
JSON（结构化数据）一种机器容易读取的数据格式，里面保存项目地址、评分、状态和证据覆盖率等结果。
HTTP POST（提交数据）把 JSON 发送到接收地址时使用的一种标准网络请求方式。
